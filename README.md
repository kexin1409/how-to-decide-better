# 高性价比避坑指南

> 没时间啃完行为金融学，用三大经典，识破大脑让你亏钱的套路。

循「高性价比」系列第六本。前五本（[饮食](https://github.com/kexin1409/how-to-eat-better)、[睡眠](https://github.com/kexin1409/how-to-sleep-better)、[运动](https://github.com/kexin1409/how-to-exercise-better)、[搞钱](https://github.com/kexin1409/how-to-earn-better)、[投资](https://github.com/kexin1409/how-to-invest-better)）之后，这本把镜头从外部周期转向**内部人性**：投资第五本讲「你在经济周期的哪一段」，这本讲「你的大脑在哪个段位」——亏钱不一定是运气差，也不一定是知识不够，而是一套可以预测的犯错方式。

## 这是什么

一本以三本经典为来源的结构化整理：

- **《穷查理宝典》**（查理·芒格，中信出版集团，2017）第三讲「人类误判心理学」——25 种心理倾向的原始清单；
- **《投资心理学》**（John R. Nofsinger，机械工业出版社）——过度自信、处置效应、心理账户等偏差的账户数据与实验证据；
- **《非理性繁荣》**（Robert J. Shiller，中国人民大学出版社）——泡沫心理与全球市场史。

这本书做的是：

- 把损失厌恶、过度自信、锚定、处置效应、从众、确认偏差、熟悉度偏差、心理账户、情绪影响、泡沫心理，拆成 **146 条可检索的条目**；
- 每条沿用系列统一的「性价比」框架：**成本**（钱/时间/毅力）× **收益** × **证据等级**（A/B/C）× **性价比**，并沿用 **风险** 档（低/中/高，指「不纠偏可能亏掉什么」）；
- 所有条目注明出处：原书章节 + 其中引用的原始研究（Barber & Odean、Odean、卡尼曼与特韦尔斯基、塞勒、席勒等）。

**不构成投资建议。** 书中所有研究结论都是对历史数据和实验的描述，不是对未来收益的承诺。

## 证据分级与性价比口径

- **证据等级**：A = 原书引用有具体数字、可复现实验或大规模账户数据的研究（如巴伯与奥丁 78000 户回测、卡尼曼与特韦尔斯基的前景理论实验、席勒 36 国涨跌统计）；B = 单一研究或较实在但偏定性的论据；C = 芒格式经验观察、作者观点或业界共识。
- **性价比**：由「收益量级 + 三项成本（钱/时间/毅力）」合成的作者判断，与证据等级无关。「一般」不等于不该做。
- **风险档**：低 = 不纠偏或照做主要亏时间/小额成本；中 = 可能亏损本金一部分；高 = 可能大幅回撤。

## 内容与来源

- 12 节 146 条；证据 A 72 / B 38 / C 36；性价比 极高 97 / 高 42 / 一般 7；标注争议 5 条。
- 所有条目整理自《穷查理宝典》第三讲、《投资心理学》第 1—12 章、《非理性繁荣》第 1、7、8 章；书中涉及的 Barber & Odean、Odean、Shefrin & Statman、De Bondt & Thaler、Benartzi & Thaler、Duflo & Saez、Hirshleifer & Shumway 等研究均转述自上述原书的引用。
- 本书只整理公开出版物中的研究结论与数据，不添加原书之外的新数据；有争议的条目（如本土偏差的效应量、情绪指标的时变性、确认偏差可否根治）在备注中如实标注反方证据。
